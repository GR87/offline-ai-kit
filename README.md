# offline-ai-kit

Інструкція (скіл) для AI-агента: ставить на ноутбук локальну модель і офлайн-бібліотеку Kiwix, з'єднує їх і перевіряє, що все працює без інтернету.

## Як користуватись

1. Скачайте `offline-ai-kit.zip` зі сторінки [Releases](https://github.com/GR87/offline-ai-kit/releases/latest) і розпакуйте.
2. Дайте теку своєму агенту (Claude Code, Codex) і напишіть: «Постав офлайн-AI за скілом offline-ai-kit».
3. Робіть це, поки інтернет є: завантаження триває кілька годин.

## Що всередині

- [`offline-ai-kit/SKILL.md`](offline-ai-kit/SKILL.md) — покрокова інструкція для агента.
- `offline-ai-kit/files/kiwix-list.txt` — 45 файлів бібліотеки (149,5 ГБ) з контрольними сумами.
- `offline-ai-kit/files/*.sh`, `kiwix-serve.plist.template` — завантаження, перевірка, автозапуск сайту `localhost:8080`.
- `offline-ai-kit/files/offline-test/` — тест моделі в пісочниці без мережі.

## Що треба знати заздалегідь

- Перевірено на macOS (MacBook Pro M4 Pro, 24 ГБ), листопад 2026. Частину для Windows і Linux не тестовано.
- Потрібно до 200 ГБ вільного місця; є менші набори на 5, 16 і 97 ГБ.
- Агент ставить пакети через Homebrew, Rosetta й автозапуск (LaunchAgent) для локального сайту.
- Мала модель (9B) — стороння збірка на основі Qwen зі знятими обмеженнями; офіційної Qwen3.8 на 9B немає. Альтернативу названо в інструкції.
- Модель помиляється в числах. Дози й пропорції звіряйте зі статтею, яку вона назвала.
